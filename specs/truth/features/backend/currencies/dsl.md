# 後端介面 DSL

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 後端實作語意 |
| --- | --- | --- | --- | --- |
| `系統使用已封存的可用幣別目錄` | 無 | 不支援 | 無 | 以隔離測試資料庫建立句中帳號、有效 session 與指定業務資料；檢查擁有者關聯和已落地狀態；回寫業務識別供唯一 Act 使用，不必由 API 重演前序操作。 |
| `使用者查詢可用幣別` | 無 | 不支援 | 無 | 呼叫公開 GET /api/currencies；記錄完整目錄回應，不改動幣別快照。 |
| `日幣為零位小數且美元為兩位小數` | 無 | 不支援 | 無 | 200；目錄 JPY minorUnit=0、USD minorUnit=2，代碼、名稱與可用狀態均等於資料庫封存快照。 |
