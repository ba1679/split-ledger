# 旅行帳本總覽

## 目標與範圍

開啟旅行後，使用者能先讀到個人花費與應收應付，並能一眼找到新增支出的入口。本次調整旅行帳本 `/trips/:tripId`、旅行清單 `/trips` 和受影響的裝置導覽。沿用既有支出表單、統計、分帳、權限與旅行管理流程。

## 手機

- **M1** 手機頂部顯示旅帳 Logo。旅行總覽依序顯示旅行名稱、日期、個人花費、應收應付與逐筆支出。
- **M2** 旅行總覽底部提供我的旅行、同行者、分帳結算。「我的旅行」直接開啟首頁。右下角固定的浮動 `＋` 與導覽在視覺上分開，無障礙名稱為「記一筆」。
- **M3** 全站設定齒輪只出現在「我的旅行」首頁的底部導覽，點開底部面板。

## 桌機

- **D1** 首屏在頁首下方並排顯示個人花費（左）與應收應付（右）。逐筆支出在雙欄下方使用主內容全寬。接近手機寬度時，摘要可堆疊以維持可讀性。
- **D2** 頁首右側顯示「＋ 記一筆」。往下捲過完整頁首時，精簡固定頁首顯示旅行名稱與同一個新增支出入口。
- **D3** 側欄的「我的旅行」通往旅行清單。旅行內依序提供旅行總覽、同行者、分帳結算，並標示目前所在頁。從同行者或結算可直接回到同一趟旅行的總覽。全站設定齒輪只出現在首頁側欄底部，點開置中面板。

## 共用行為

- **C1** 個人花費依原幣別分列，整區共用「看分析」，進入目前旅行的分析頁。應收應付摘要依原幣別呈現既有成員淨額，詳細資訊可從分帳結算頁查看。
- **C2** 手機與桌機都從旅行卡片右上角的鉛筆按鈕開啟下拉選單。選單提供編輯旅行日期、更換縮圖與移至垃圾桶。卡片內的開啟帳本連結和編輯按鈕可獨立使用。日期編輯完成後留在清單，並顯示保存結果。
- **C3** 空帳本可直接記一筆。沿用既有載入、重試及旅行不可用狀態。固定控制項應避開安全區，且不能遮住可聚焦的操作或最後一筆支出。
- **C4** 垃圾桶清單的入口在首頁上方。全站設定集中支出分類、語系、登出。語系列展開繁體中文與 English，勾選目前語言，選取後立即套用並收合。

## 驗收

| 情境 | 預期 |
| --- | --- |
| 手機進入有多幣別支出的旅行，再捲到清單 | 首屏優先顯示摘要。底部三個導覽入口及右下角的「記一筆」可用，末筆可完整捲入可視區。 |
| 桌機查看旅行，捲到較早支出 | 兩區摘要並排、支出全寬。精簡頁首顯示旅行名稱與「＋ 記一筆」，可開啟這趟旅行的新增支出。 |
| 桌機從側欄進入同行者或結算，再點「旅行總覽」 | 回到同一趟旅行，側欄更新目前頁標示。 |
| 任一裝置點「看分析」 | 開啟同一趟旅行的分析，摘要中的金額維持分幣別。 |
| 任一裝置從旅行卡片開啟編輯選單並取消 | 可用鍵盤操作選單；取消後資料不變，焦點回到適當入口。 |
| 任一裝置從首頁開啟全站設定 | 找得到支出分類、語系及登出。旅行頁無全站設定入口，可直接回首頁。 |

本次依賴的視覺位置與狀態見 [UI 設計交接](ui/ui-plan.md)。手機分析入口、由分析回到帳本及旅行管理選單的變更，與前端 feature、DSL 和既有驗證同步。
